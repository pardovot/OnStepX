OnStepX Firmware

Browser flashing for the UMi17 and SA-17M mounts. No software to install.

This browser cannot flash. Web Serial is only available in desktop Chrome, Edge and Opera. Use one of those, or follow manual flashing below.

Home the mount before you flash. After the update the firmware treats the absolute motor position as being at the home position. If the telescope is somewhere else when it first powers up, the east, west and horizon limits are measured from the wrong origin. Park or home the mount first, or re-home it immediately afterwards.

Upgrading from V2 clears all settings. Site location, limits, park and home positions, PEC data, the pointing model and any saved catalog objects are reset to defaults and must be set up again.

The two builds are not interchangeable. They differ in steps per degree, declination direction and worm rotation, so flashing the wrong one gives a mount that tracks and slews incorrectly rather than one that obviously fails. Check which mount you have before clicking.

Flashing

  1. Connect the controller to the computer with a USB cable.
  2. Click the button for your mount.
  3. Pick the controller's serial port in the browser prompt.
  4. Wait for erase, write and verify to finish, about a minute.

Tools

These talk to a controller that is already running. Only one program can hold the serial port at a time, so disconnect here before flashing, and close any other software that is connected to the mount.

Is the FRAM working?

The mount saves its position to FRAM every second. If the chip is not wired correctly the firmware still runs, so the failure is easy to miss until settings start disappearing. This test writes a value, reboots the controller, and reads it back, which is the only way to prove it actually persisted.

This reboots the mount. Do not run it while slewing or imaging. The drift threshold is changed during the test and put back afterwards.

Serial console

Commands follow the OnStep protocol, so they start with : and end with #. Some return a value, some return 0 or 1, and some return nothing at all.

These two change or lose state.

Not connected.

If no port appears, the USB serial driver is probably missing. These boards use a CP2102 or CH340 chip, both have drivers available from their vendors.

If it says "Failed to initialize", close the dialog entirely rather than using its Back button, then click Install again. Back leaves the installer stuck on "connecting", closing it releases the serial port properly.

If it keeps failing, hold the BOOT button on the controller while clicking Install.

Manual flashing

For Firefox, Safari, or any machine where browser flashing is not an option, download the firmware for your mount from the releases page and write it with Espressif's Flash Download Tool:

  • Chip: ESP32
  • Single file OnStepX-<version>-<mount>.bin at address 0x0
  • SPI settings: QIO, 80MHz, 4MB

The parts archive on the release contains the separate bootloader, partition table, boot_app0 and firmware images with their offsets, for tools that expect the conventional four file layout.

Built from pardovot/OnStepX. Each release is compiled from a tagged commit, and both mount images come from the same build.
