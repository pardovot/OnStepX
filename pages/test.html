Old releases

Not linked from anywhere. For testing upgrade paths.

These are superseded builds. Do not use them to run a mount. They have no absolute motor position, so none of the cable wrap or horizon protection exists, and the meridian flip behaves differently.

When you are done, go back to the current firmware and install V3.

Both are UMi17 only, rebuilt from the original release assets into a single image. Their flash mode and frequency were preserved rather than forced to match V3, so they run exactly as they originally shipped.

Testing the upgrade path

Installing one of these and then V3 from the main page exercises the two things the V3 notes describe but that are otherwise hard to observe:

  1. Settings are wiped, because V3 stores them under a different key.
  2. V3 anchors its absolute position to the home position on the first boot, so park or home the mount before installing V3.

Desktop Chrome, Edge or Opera. Firefox and Safari cannot talk to serial ports.
